# 9_Assets

The showcase of Unicorn: what the [zUrp Astronomics website](https://zurp-astronomics.github.io/unicorn/) and this repository's
README display. It belongs to the zUrp Astronomics organisation, which keeps it consistent across
all its products.

| File | What it is | Shown on |
|---|---|---|
| `zurp.yml` | the product sheet: name, tagline, slogan, section, status, description, accent colour | the website, the organisation README |
| `unicorn.webp` | the poster, 1254 × 1254 | the website, the README header |
| `unicorn-main-board.webp` | main board, 3D view | the README |
| `unicorn-main-board-top.webp` | main board, top | the README |
| `unicorn-main-board-bot.webp` | main board, bottom | the README |
| `unicorn-shc.webp` | Smart Hand Controller, 3D view | the README |
| `unicorn-shc-top.webp` | Smart Hand Controller, top | the README |
| `unicorn-shc-bot.webp` | Smart Hand Controller, bottom | the README |
| `unicorn-brake-top.webp` | brake module, top | the README |
| `unicorn-brake-bot.webp` | brake module, bottom | the README |

Images here are WebP copies sized for display. Their full-size originals stay where they are produced: `1_Board/Main-board/TeenAstro_Redux__Main_Board_v2.6.4__2_3D-view_readme.png`, `1_Board/Main-board/TeenAstro_Redux__Main_Board_v2.6.4__2_3D-view_top.png`, `1_Board/Main-board/TeenAstro_Redux__Main_Board_v2.6.4__2_3D-view_bot.png`, `1_Board/SHC/TeenAstro_Redux__SHC_v1.5.2__2_3D_view_readme.png`, `1_Board/SHC/TeenAstro_Redux__SHC_v1.5.2__2_3D_view_top.png`, `1_Board/SHC/TeenAstro_Redux__SHC_v1.5.2__2_3D_view_bot.png`, `1_Board/Brake-module/TeenAstro_Redux_Brake_Module_v1.1_2_3D-view_top.png`, `1_Board/Brake-module/TeenAstro_Redux_Brake_Module_v1.1_2_3D-view_bot.png`.

The sheet is read and checked by the website at each build: its format is described in
[`content/README.md`](https://github.com/zUrp-Astronomics/zurp-astronomics.github.io/blob/main/content/README.md)
of the website's repository.
